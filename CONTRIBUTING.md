# Contributing to GN (beta)

Thank you for helping improve GN. The project aims to make sample-size planning understandable and statistically transparent.

If you discover a bug or a statistical discrepancy, please open an issue at **https://github.com/matteo-toscani-24-01-1985/Nagus/issues** (confirm the repository is publicly accessible). Include the selected analysis, effect size, target power, alpha, allocation details, expected versus actual result, relevant screenshots if helpful, and clear steps to reproduce the issue. Please **do not share sensitive research or identifiable participant data**.

Contributions of accessibility fixes, clearer methods descriptions, worked research examples, software tests, reference validation and code changes are welcome. For changes to power formulas, please include a reference statistical method, a reproducible comparison with a trusted implementation, and a clear explanation of the assumptions. Describe approximations openly instead of presenting them as exact.

For code changes, update `src/app.js`, `src/math.js` or `src/template.html`, run `python scripts/build.py`, and execute the relevant tests before proposing the change. Please use the public issue tracker to discuss larger changes before implementing them.

The beta is exploratory. Contributors should not interpret numeric cross-checks as blanket clinical or high-stakes research validation.
