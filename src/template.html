What are you studying?

Start with your dependent variable (outcome) and research question.

t tests and ANOVA require a suitable numerical outcome. A single ordered rating is ordinal and is not treated as continuous automatically.
We recommend the statistical test automatically.
2

Describe your independent variables

Each categorical factor can be between participants or measured repeatedly.

Factors are group variables. Continuous predictors enter a regression or serve as covariates in ANCOVA.

“Between participants” means different people in different groups. “Within participants” means the same people complete all conditions of that factor. Mixing the two gives a mixed ANOVA.

How many participants in each independent group?

Only between-participant groups need allocation. Repeated measurements do not create additional participants.

Enter relative weights, not sample sizes: 1 and 2 means a 1:2 allocation. The app calculates the numbers needed in every group.

Examples: age in years, baseline blood pressure (mmHg), or a continuous predictor.
Separate names with commas. The order matches the numbered predictors.
This analysis needs no grouping factor. Each observation should come from an independent participant (except for paired tests).
3

Which effect matters most?

The sample size is calculated for the specific hypothesis you choose—not necessarily every effect in the study.

✓
Independent-samples t test

E.g., Treatment × Time asks whether the treatment difference changes over time. An interaction does not test either main effect by itself.
4

Choose the power and effect size

Use a justified expected effect size, or calculate one from previous findings.

Enter a percentage such as 87.5 for 87.5% power.
Chance of detecting the assumed effect if it is real.
False-positive probability for this specific test.
Use an absolute magnitude.
Use a one-sided test only if justified before collecting data.

Binary outcome: expected reference / group 1 rate

Enter a proportion, not a percentage (e.g., 0.40).
Cohen’s h is a magnitude; the baseline rate and direction affect actual power.

Repeated measurements: correlation assumptions

Default 0.50; enter the expected correlation across repeated occasions for the same participant.
1 = sphericity assumed. Below 1 gives only a rough Greenhouse–Geisser sensitivity scenario.

For the model with equal pairwise correlations and variances, sphericity is satisfied (ε = 1). A non-1 ε should be treated as an approximation, not a fully specified covariance model.

About GN

GN — Guided N Estimator is an accessible, browser-based tool for guided statistical power analysis and sample-size planning. It helps researchers select a design, specify the effect they want to detect, examine assumptions, and produce a transparent sample-size summary.

How to cite GN

Until a journal article or archived release is available, please cite the software version used. The draft reference below is provisional.

Toscani, M., & Metzger, A. (2026). GN: Guided N Estimator (Version 1.0 beta) [Computer software]. GitHub. https://github.com/matteo-toscani-24-01-1985/Nagus

Confirm the repository contains this release and that the author details are approved before citing. When a DOI is assigned, add it here and to CITATION.cff. A later journal publication can be cited as the methodological paper; the software version can still be cited separately for reproducibility.

About this beta

GN v1.0 beta is under active development. Numerical checks have been performed for selected analyses, but the software is not fully validated or peer reviewed. Users should examine the statistical assumptions and independently check consequential analyses.

The methods and limitations are described in the repository's technical supplement. Calculations run locally in the browser; no account is needed.

Bugs, feedback & contributions

If you notice a bug, a questionable statistical result, confusing wording, or an unsupported research design, we would appreciate a reproducible report. Improvements to the code, documentation, accessibility and independent numerical checks are welcome.
