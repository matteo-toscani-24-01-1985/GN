# About GN and citation instructions

**GN — Guided N Estimator** is an accessible, browser-based statistical power analysis and sample-size planning tool for researchers. The software guides choices about study design, independent and repeated conditions, target hypotheses and assumptions.

**Developed by:** Matteo Toscani and Anna Metzger (listed in that order provisionally, pending approval of manuscript authorship and affiliations).

## Provisional software citation (v1.0 beta)

Toscani, M., & Metzger, A. (2026). *GN: Guided N Estimator* (Version 1.0 beta) [Computer software]. GitHub. https://github.com/matteo-toscani-24-01-1985/Nagus

## Bug reports, feedback and contributions

GN v1.0 beta is under active development. If you encounter a bug, numerical discrepancy, unclear instruction or unsupported design, please consider reporting it at https://github.com/matteo-toscani-24-01-1985/Nagus/issues with a reproducible example. Independent numerical checks, code improvements, documentation corrections, usability feedback and contributions are very welcome. Please do not upload identifiable participant data.

## Version status

GN v1.0 beta is not yet exhaustively validated or peer reviewed. An estimate depends on the user's statistical assumptions. Complex or high-stakes designs should be independently checked.
